# Urban Sensor Data Collector

## Application Access
The sensor data collection tool is hosted and publicly accessible via GitHub Pages:
- **URL**: `https://bhargavi-nemade.github.io/uc-sensor-data/`

---

## 📱 Testing & Data Collection Instructions

### Prerequisites
- An iPhone (iOS 13+) running Safari.
- An active internet connection (HTTPS secure context is required by iOS to enable the browser's hardware motion sensor APIs).

### Step-by-Step Instructions
1. **Open the App**: Navigate to the live GitHub Pages URL above using Safari on your iPhone.
2. **Initialize Recording**: Tap the **"Start Recording"** button.
3. **Grant Permissions**: When iOS prompts for motion and orientation access, tap **Allow**. *(Note: If permission was previously denied, it can be reset via Settings > Safari > Motion & Orientation Access).*
4. **Generate Motion Data**: Move or walk with the device to collect data. Data points collected will be displayed in the live counter.
5. **Export CSV**: Tap **"Stop & Download CSV"**. 
6. **Access File**: Confirm the download prompt. The resulting `iphone_sensor_data.csv` file will be saved directly to the iPhone's **Files** app under **Downloads**.
